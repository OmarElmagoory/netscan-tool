# Netscan Tool

أداة لفحص الشبكة وتحليل الترافيك ومعرفة قرب الأجهزة من الراوتر.

## 🚀 خطوات التشغيل
1. تثبيت الأداة:
   ```bash
   chmod +x install.sh
   ./install.sh
# أداة netscan

## 📌 الوصف
أداة لفحص الشبكة المحلية، تقوم بـ:
- اكتشاف الأجهزة المتصلة (IP، MAC، Vendor).
- قياس زمن الاستجابة (Latency) وترتيب الأجهزة حسب القرب الفيزيائي من الراوتر.
- مراقبة الترافيك وتحديد عدد الحزم المرسلة من كل جهاز.
- تحليل استهلاك الشبكة وتحديد أكثر الأجهزة نشاطًا.

---

## ⚙️ خطوات التثبيت
1. تأكد من وجود الملفين التاليين:
   - netscan (ملف الأداة التنفيذي)
   - install.sh (سكربت التثبيت)
2. افتح الطرفية في نفس المجلد ونفّذ الأوامر التالية:
   chmod +x install.sh
   ./install.sh

---

## ▶️ طريقة التشغيل
لتشغيل الأداة:
   sudo netscan

---

## 📂 الملفات الناتجة
- ~/netscan/netscan_results.txt → قائمة الأجهزة (IP + MAC + Vendor + Latency)
- ~/netscan/netscan_latency.png → رسم بياني للقرب الفيزيائي من الراوتر
- ~/netscan/netscan_traffic.csv → عدد الحزم لكل جهاز
- ~/netscan/netscan_traffic.png → رسم بياني للترافيك

---

## ⚠️ ملاحظات
- يجب تشغيل الأداة بصلاحيات المسؤول (sudo)
- تأكد من أن كرت الشبكة في وضع Bridged إذا كنت تستخدم VMware
- الأداة تعمل على توزيعات Linux وتحتاج Python 3 وnmap وscapy
